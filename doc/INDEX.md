# Lavender Messenger Web Client — Документация

Индекс всех документов проекта веб-клиента. Читать при каждом старте новой сессии.

**Версия:** v0.1.0
**Дата:** 2026-06-10
**Статус:** базовая реализация (мобильный чат)

---

## Быстрый старт

1. **ARCHITECTURE.md** — обзор архитектуры, стека, структуры
2. **CODEBASE.md** — подробное описание каждого модуля
3. **IOS.md** — iOS-специфичные решения (SafeArea, клавиатура, стримы)
4. **STATE.md** — Zustand store (нормализованная структура)
5. **GRPC.md** — gRPC клиент, стриминг, lifecycle
6. **PITFALLS.md** — подводные камни
7. **TASKS.md** — таск-трекер

## Правила

- При старте новой сессии: ARCHITECTURE.md → CODEBASE.md → TASKS.md → PITFALLS.md
- Для актуальной информации по серверу/Android: читать `/root/msg/doc/`
- После каждого значимого изменения: обновлять TASKS.md + соответствующие документы
