# Lavender Messenger Web Client — Документация

Индекс всех документов проекта веб-клиента. Читать при каждом старте новой сессии.

---

## Быстрый старт

1. **ARCHITECTURE.md** — архитектура веб-клиента (стек, структура, компоненты)
2. **SERVER_INTEGRATION.md** — интеграция с сервером (gRPC, API, протоколы)
3. **ANDROID_PARITY.md** — соответствие функциональности Android-клиента
4. **PITFALLS.md** — подводные камни и известные проблемы
5. **TASKS.md** — таск-трекер (сделано/не сделано по приоритетам)

---

## Файлы документации

### Архитектура и дизайн

| Файл | Назначение | Когда читать |
|------|-----------|-------------|
| `ARCHITECTURE.md` | Стек технологий, структура проекта, компоненты, роутинг | **Всегда в начале** |
| `SERVER_INTEGRATION.md` | gRPC API, протоколы, потоки данных, интеграция с сервером | **При работе с сервером** |
| `ANDROID_PARITY.md`  | Функциональное соответствие Android-клиенту, различия | При реализации UI/UX |
| `UI_COMPONENTS.md`     | Библиотека компонентов, дизайн-система | При разработке интерфейса |

### Разработка

| Файл | Назначение | Когда читать |
|------|-----------|-------------|
| `TASKS.md` | Таск-трекер: сделано по версиям, бэклог по приоритетам | В начале сессии |
| `PITFALLS.md` | Подводные камни и известные проблемы | **Перед началом работы** |

### Контекст проекта Lavender

| Файл | Назначение | Когда читать |
|------|-----------|-------------|
| `LAVENDER_CONTEXT.md` | Обзор проекта Lavender Messenger: сервер, Android, AI-сервисы | Для общего контекста |

---

## Правила

- При старте новой сессии: ARCHITECTURE.md → SERVER_INTEGRATION.md → TASKS.md → PITFALLS.md
- После каждого значимого изменения: обновлять TASKS.md + соответствующие документы
- Документация распределена по файлам и проиндексирована в INDEX.md
